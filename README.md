# Tic-Tac-Toe Game 

A simple and interactive text-based Tic-Tac-Toe game developed using Python.

## Features 
- Multi-player mode (Play with 2 players as X and O).
- Runs directly inside your command line or terminal.
- Clean, readable, and beginner-friendly Python code.

## How to Run 
1. Make sure you have Python installed on your system.
2. Open your Terminal or Command Prompt and run the following command:
   ```bash
   python tic_tac_toe.py
   ```
